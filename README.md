## 🛠️ Layanan Kami (Our Services)

Kami melayani berbagai kebutuhan AC untuk rumah tinggal, kantor, ruko, cafe, hingga instansi pemerintah di Siantar:

*   **Cuci AC Rutin / Cleaning System (Clean & Fresh):** Membersihkan debu dan jamur penyebab bau dan tidak dingin.

*   **Jual Beli AC Second/Baru:** Menyediakan unit AC berkualitas dengan garansi toko.

---

## 📅 Tips Merawat AC biar Awet & Hemat Listrik

*   Lakukan cuci AC rutin minimal **3-4 bulan sekali** untuk mencegah penumpukan debu.
*   Atur suhu remote ideal di **22°C - 24°C** agar kompresor tidak bekerja terlalu keras.
*   Pastikan ruangan tertutup rapat saat AC menyala.
